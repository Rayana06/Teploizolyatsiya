# Визуальный референс: ТЕХНОНИКОЛЬ

Ссылку предоставила студентка: https://www.tn.ru/catalogue/teploizolyatsiya/

Проверка 06.09.2026: страница открыта в браузере, изучены карточки и их computed styles; правила hover прочитаны из CSS страницы. Прямое скачивание HTML блокируется сайтом, но браузерная проверка выполнена.

Для трёх основных цветов на защите назвать красный, белый и серый из первых трёх строк. Вспомогательные цвета не выдавать за дополнительные основные. Названия карточек сайта написаны прописными буквами; в макетах сохраняются названия товаров, в подготовленном CSS предусмотрен `text-transform: uppercase`.

Шрифт источника — `Proxima, sans-serif`. В проекте выбран Arial как доступный шрифт: его нельзя называть скопированным Proxima. Структура сайта переработана в фиксированный вертикальный интерфейс по требованию преподавателя.

Фраза для защиты: «Я взяла стилистику каталога теплоизоляции ТЕХНОНИКОЛЬ: красный акцент #E2000E, белые карточки, серый текст, скругление карточек 4 пикселя и тень. При наведении изображение увеличивается на 4%, а название меняет цвет на #CC3333. Вёрстка адаптирована под задание: вертикальная лента и нижние вкладки».

В `insulation-materials.css` заимствования перечислены комментарием и реализованы предметными классами. Статический SVG не выполняет hover, поэтому отдельный SVG с двумя состояниями служит образцом для Figma; само поведение реализовано в CSS.

Источники товара, характеристик и цен следует фиксировать отдельно. Ссылка на каталог дизайна не подтверждает цены и характеристики других производителей из исходных макетов.
