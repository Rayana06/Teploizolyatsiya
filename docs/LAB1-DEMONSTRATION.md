# Лабораторная 1: сценарий показа Теплощита

Это план съёмки и репетиции. Скриншоты ещё не вложены; файл не выдаётся за готовый комплект доказательств. Конкретное распределение внутри диапазонов согласовано с порядком из переданного задания.

## Перед показом

1. Запустить Docker Desktop, убедиться, что контейнер MinIO работает. Открыть консоль `http://localhost:9011` и бакет `insulation-materials`. Не включать пароль в скриншоты.
2. Запустить приложение по инструкции `insulation-backend/README.md`. Открыть `http://localhost:3000/insulation-materials/catalog`.
3. Открыть файл Figma с тремя актуальными макетами, сайт-референс и GitHub с веткой `lab1-insulation-materials`. Локальные SVG и локальная ветка не заменяют эти два пункта.
4. Подготовить отдельный файл скриншотов, реальные конспекты лекций и письменные ответы. Если были замечания преподавателя — отдельный файл с каждым замечанием, объяснением исправления и подтверждающим скриншотом.

| 15 | `views/insulation-material-catalog.hbs` | Цикл `each`, `src` изображения и адрес видео |

В Network выбирать запрос документа страницы, а не запрос CSS или видео. В Response виден HTML, полученный от сервера. Elements показывает текущий DOM — это другая вкладка и она не заменяет требуемый Response. Если карточки не обновляются из-за кеша, перезагрузить страницу с открытой вкладкой Network; не рисовать строки запросов вручную.

## Короткая репетиция поведения

| Действие | Ожидаемый результат |
| --- | --- |
| Открыть каталог без цены | Шесть материалов, пустое поле с подсказкой |
| Ввести 322.21 | Два материала |
| Ввести 322.22 | Четыре материала; равная границе цена включается |
| Ввести 0 | Пустой результат и ссылка возврата |
| Открыть `/feed/3?next=true` с префиксом `/insulation-materials` | Материал ID 4 |
| Открыть `/feed/6?next=true` с тем же префиксом | Возврат к первому опубликованному материалу |
| Открыть `/feed/7` с тем же префиксом | 404: черновик не публикуется в ленте |
| Изменить поле черновика и перезагрузить страницу | Исходное значение восстановлено, сохранения нет |
| Нажать «Больше» | Описание раскрывается без клиентского JavaScript |
| Изменить ширину окна | Фиксированная композиция остаётся прежней |

Две марки RAFINAD имеют одинаковую подтверждённую цену, но разные артикулы и назначение. Подробные расчёты и источники — в `design/MATERIAL-SOURCES.md`. Не объясняй совпадение цен тем, что это один товар.
