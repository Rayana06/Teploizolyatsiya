# Лабораторная работа №4 — авторизация

Backend системы «Теплощит» на NestJS. В лабораторной работе реализованы регистрация, сессионная аутентификация через Cookie `sessionId`, хранение сессий в Redis и разграничение доступа к REST API.

## Реализовано

- `POST /api/users/register` — регистрация пользователя;
- `POST /api/users/authenticate` — проверка email и пароля, создание сессии в Redis и установка HttpOnly Cookie;
- `POST /api/users/logout` — удаление сессии и Cookie;
- публичные GET-методы списка и ленты услуг;
- защищённые методы создания, публикации, удаления услуги и изменения отметки «Нравится»;
- ответы `401 Unauthorized` для гостя и `403 Forbidden` при обращении к чужому ресурсу;
- документация Swagger с Cookie-аутентификацией.

## Запуск

1. Скопировать `.env.example` в `.env`.
2. Запустить PostgreSQL, Redis, MinIO и Adminer: `docker compose up -d`.
3. Установить зависимости: `npm install`.
4. Собрать и запустить приложение: `npm run build`, затем `npm start`.
5. Открыть Swagger: `http://localhost:3001/swagger`.

Для подготовки демонстрационных данных выполнить в Adminer файл `database/lab4-demo-prepare.sql`.

## Проверка

При запущенных PostgreSQL, Redis и MinIO выполнить `npm test`. Тест проверяет публичный доступ, создание Redis-сессии, успешную публикацию владельцем, ответы `401` и `403`, а также завершение сессии.

Коллекция запросов находится в `postman/Лабораторная-4.postman_collection.json`, диаграмма последовательности — в `docs/lab4`.
