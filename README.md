
# Лабораторная работа №1

**Тема:** оценка эффективности теплоизоляции здания.

**Задание**: создание дизайна приложения в `figma`, базовая шаблонизация для `услуг`, развертывание `Minio`

В предметной области услугами являются типы изоляционных материалов: минеральная вата, пенопласт и PIR-плиты. В лабораторной реализованы три страницы: лента изоляционного материала, черновик материала и каталог из шести опубликованных материалов.

## Технологии

- TypeScript и NestJS;
- Handlebars для серверной шаблонизации;
- MinIO для изображений и вертикальных видео;
- отдельный CSS без клиентского JavaScript;
- одна коллекция в памяти без базы данных.

## Запуск

Нужны Node.js и Docker Desktop. После клонирования репозитория создать `.env` из `.env.example` и заменить тестовый пароль своим.

```powershell
npm ci
Copy-Item .env.example .env
docker compose up -d
npm run minio:seed
npm run start:dev
```

Страницы приложения:

- каталог: http://localhost:3000/insulation-materials/catalog
- лента: http://localhost:3000/insulation-materials/feed
- черновик: http://localhost:3000/insulation-materials/draft
- консоль MinIO: http://localhost:9011

Порты 9010 и 9011 выбраны для MinIO этого проекта. Логин и пароль берутся из локального файла `.env`, который не публикуется в GitHub.

## Реализация задания

В приложении ровно три прикладных GET-обработчика:

1. `GET /insulation-materials/feed/1` — лента по ID. Параметр `?next=true` открывает следующий опубликованный материал.
2. `GET /insulation-materials/draft` — единственный материал со статусом `draft`.
3. `GET /insulation-materials/catalog?insulationMaxPrice=1300` — серверная фильтрация опубликованных материалов по максимальной цене за м².

Количество лайков вычисляется по вложенным ID пользователей. Черновик можно заполнять, но изменения не сохраняются. Материал со статусом `deleted` не отображается. Изображения и видео выдаёт MinIO по разным ключам из коллекции.

Команда `npm test` компилирует приложение и выполняет пять HTTP-проверок основных требований.
