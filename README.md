# Лабораторная работа №5 

## Страницы приложения

### 1. Лента — `/`

Гостевая страница последовательного просмотра услуг. Каждая карточка содержит изображение, видео, тип, дату публикации, название, бренд, описание, толщину, цену, назначение, число отметок «Нравится» и кнопку **«Подробнее»**.

Если `imageUrl` или `videoUrl` равны `null`, компонент `MaterialMedia` подставляет локальные файлы из `public/default-media`. То же происходит при ошибке загрузки указанного файла.

### 2. Плитка — `/catalog`

Каталог карточек в сетке. Панель фильтрации повторяет логику первой лабораторной и содержит:

- ползунок максимальной цены от **229,63** до **1 570,15 ₽/м²**;
- кнопку **«Подобрать»** — до её нажатия изменение ползунка не влияет на карточки;
- счётчик найденных услуг.

Выбранная и применённая максимальные цены хранятся в состоянии страницы отдельно. Компонент `CatalogFilters` получает границы цены, текущее значение и callback-функции изменения и применения через props. Отфильтрованный по цене массив вычисляется с помощью `useMemo`.

### 3. Подробности — `/materials/:materialId`

Показывает одну услугу из той же mock-коллекции: изображение, видео, характеристики, назначение, дату и число отметок. Есть кнопка **«Назад»**. Для неизвестного идентификатора выводится сообщение «Материал не найден».

## Нижняя навигация

Панель `BottomNav` закреплена снизу и содержит четыре пункта:

| Пункт | Состояние для гостя | Назначение |
|---|---:|---|
| Лента | доступен | переход на `/` |
| Добавление | недоступен | требует авторизации |
| Плитка | доступен | переход на `/catalog` |
| Вход | недоступен | не реализуется в ЛР5 |

## Компоненты и props

- `MaterialCard` получает `material` и вариант отображения `feed | tile`.
- `MaterialMedia` получает URL изображения и видео, название и признаки показа видео/компактного режима.
- `MaterialFacts` получает услугу и признак компактного режима.
- `CatalogFilters` получает границы цены, выбранное значение и callback-функции изменения и применения.
- `BrandHeader` и `BottomNav` не имеют props.

Props неизменяемы: дочерние компоненты вызывают переданные callback-функции, а состояние меняет родительская страница `CatalogPage`.

## Используемые хуки

| Хук | Файл | Назначение |
|---|---|---|
| `useState` | `CatalogPage.tsx` | выбранная и применённая максимальные цены |
| `useState` | `FeedPage.tsx` | номер текущей карточки ленты |
| `useState` | `MaterialMedia.tsx` | ошибки загрузки, воспроизведение, звук, время и длительность видео |
| `useMemo` | `CatalogPage.tsx` | фильтрация по максимальной цене без лишнего пересчёта |
| `useEffect` | `CatalogPage.tsx` | изменение title при обновлении результата и cleanup при размонтировании |
| `useEffect` | `MaterialMedia.tsx` | создание/очистка анимации увеличения и плавное обновление прогресса видео |
| `useRef` | `MaterialMedia.tsx` | ссылки на video, его контейнер и объект анимации без повторного рендера |
| `useParams` | `MaterialDetailsPage.tsx` | чтение `materialId` из URL |
| `useNavigate` | `MaterialDetailsPage.tsx` | возврат на предыдущую страницу |
