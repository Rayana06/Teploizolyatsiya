# Лабораторная работа №1

**Тема:** Оценка эффективности теплоизоляции здания. Услуги - типы изоляционных материалов (минвата, пенопласт, PIR-плиты), заявка - расчет теплопотерь и экономии энергии после утепления на указанной площади для каждого варианта материала.

**Задание**: создание дизайна приложения в `figma`, базовая шаблонизация для `услуг`, развертывание `Minio`

## Запуск

1. Запустить MinIO: `docker compose up -d`.
2. Собрать приложение: `npm run build`.
3. Запустить сервер: `npm start`.
4. Открыть `http://localhost:3000/insulation-materials/feed`.

Страницы лабораторной: лента материалов, черновик материала и каталог материалов. Интерфейс имеет фиксированный портретный размер 390 × 844 пикселя. Фильтр каталога отправляется серверу GET-запросом. Клиентский JavaScript не используется.

Макеты находятся в каталоге `design`, документы и подписанные скриншоты для защиты — в `docs/lab1`.
